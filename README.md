# Abhay Gupta — Portfolio

A responsive portfolio for Abhay Gupta, a Java full-stack developer. Built with React, TypeScript, Vite and Tailwind CSS.

## Portfolio sections

- About and development approach
- Professional experience
- Selected software projects
- Technical skills
- Education and workshops
- Contact details and résumé download

Portfolio content is maintained in `src/services/api.ts`. The résumé PDF is stored at `public/Abhay_Gupta_Resume.pdf`.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
